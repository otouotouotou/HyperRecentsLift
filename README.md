# HyperRecentsLift

HyperOS ランチャーの最近タスク画面を、カードごと全体的に上にずらす LSPosed モジュール。
Modern Xposed API (libxposed) 102 / Kotlin。

## 動機

HyperOS 3 の最近タスク画面では一括終了ボタンが画面最下部にあり、
ジェスチャーで最近タスクを開くときに指がボタンへ触れて、
意図せず全てのタスクを終了してしまうことがある。
カードも含めて画面全体が下寄りなので、コンテナごと上にずらして回避する。

## 仕組み

- スコープは `com.miui.home` (HyperOS ランチャー) のみ
- 最近タスク画面のルート View `com.miui.home.recents.views.RecentsContainer`
  の `onFinishInflate` をフックし、生成直後に `translationY` を
  マイナス方向へ設定して全体を上にずらす
  (一括終了ボタンはこのコンテナの内側にあるため一緒に動く)
- ランチャー側が表示のたびに変形値を戻すことがあるため、
  `OnPreDrawListener` で描画のたびに値を確認して維持する
- 一括終了ボタンまわり (`clearAnimView` と `memoryAndClearContainer`、
  調査版のツリーダンプで特定) だけを単独で上にずらす (v0.6〜)
- コンテナ全体の縮小 (v0.3〜v0.5) は、横並びレイアウトでカードが
  重なって崩れたため撤去した。設定スライダー (v0.4〜v0.6) も、
  実機で詰めた値で固定することになり v0.7 で撤去した

## バージョン

- v0.8: ソース整理のみ (コメントの清書、未使用のテーマを削除)。
  挙動は v0.7 と同一
- v0.7: 値を固定化 (全体 75dp / ボタン単独 15dp)。設定画面と
  ホームアイコンを撤去し、モジュール専用アプリにした
- v0.6: 一括終了ボタンの単独の上ずらしを追加 (0〜650dp)。
  コンテナ全体の縮小とそのスライダーは撤去
- v0.5: ずらし量の範囲を 0〜100dp に変更 (v0.4 は 0〜200dp だった)
- v0.4: 設定スライダーを追加 (ずらし量 0〜200dp / 縮小率 50〜100%、
  デフォルトは 80dp / 85%)。再起動なしで反映
- v0.3: 全体の 85% 縮小を追加。ずらし量は固定 80dp のまま
- v0.2: ずらしの維持方式を変更 (v0.1 は効いたり効かなかったりだった)。
  ずらし量は固定 80dp のまま
- v0.1: 初版。生成時に 1 回だけずらす方式

## 使い方

1. LSPosed マネージャーで有効化し、スコープで「HyperOS ランチャー
   (com.miui.home)」を選ぶ
2. ランチャーを再起動する (端末の再起動でも可)
3. 最近タスク画面を開いて確認する

## ライセンス・出典

  https://github.com/ReChronoRain/HyperCeiler) の公開ソースを参照した。
